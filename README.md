# Тельер, лендинг

Одностраничный сайт сервиса «Тельер» (приложение для гостей отеля). Пять полноэкранных секций,
скролл пошаговый: одно движение колеса или один свайп переносит ровно на следующий экран.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/telier-landing/
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

Нужен Node 20 или новее. Для отправки заявок нужен `.env` (см. `.env.example`).

## Настройка EmailJS

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

```
VITE_EMAILJS_SERVICE_ID=service_xxxxx
VITE_EMAILJS_TEMPLATE_ID=template_xxxxx
VITE_EMAILJS_PUBLIC_KEY=xxxxxxxx
```

Шаблон в [Email Templates](https://dashboard.emailjs.com/admin/templates):
- **To Email:** `welcome@telier.ru`
- **Subject:** `Заявка на демо Telier`
- **Content:** `Номер: {{phone}}`
- Auto-Reply не включать

Перезапустите `npm run dev`. `.env` не коммитить.

## Деплой на GitHub Pages

Push в `main` запускает [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

Secrets в environment **DEPLOY** (Settings → Environments):
- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`

После первого успешного деплоя: Settings → Pages → Source: **GitHub Actions**.

Сайт: `https://s-mudruk.github.io/telier-landing/`

`base` задаётся через `VITE_BASE` при сборке (по умолчанию `/telier-landing/`).
Для `telier.ru` в корне добавьте в environment **DEPLOY** secret `VITE_BASE` со значением `/`.

В EmailJS dashboard добавьте URL сайта в Allowed origins.

## Из чего состоит

```
index.html            шрифты Google Fonts, favicon, meta, разметка экрана загрузки
src/main.jsx          точка входа React
src/App.jsx           все секции и все тексты: Hero, Цифры, Продукт, Преимущества, Футер
src/styles.css        токены дизайн-системы и вся вёрстка, включая мобильную выборку
src/scroll.js         Lenis, пошаговый скролл, доводка карточек в ленте
src/scene-timing.js   кривые анимации sticky-сцены «Продукт»
public/assets/        логотип, знак, фото руки, скриншоты приложения
```

## Как работает скролл

`scroll.js` перехватывает колесо, свайп и клавиши навигации, свободной прокрутки нет.
Перед каждым переходом он заново считает точки остановки: границы всех секций `.panel`
плюс центры сцен внутри `.product-track`. Дальше `lenis.scrollTo` доводит страницу до
ближайшей точки в нужную сторону, длительность зависит от дистанции (от 0.9 до 1.3 с).
Пока идёт переход, копится не больше одного жеста, поэтому быстрая прокрутка не улетает
пачкой экранов. При `prefers-reduced-motion` Lenis не создаётся и переходы мгновенные.

`attachRailSnap` в том же файле отвечает за горизонтальную ленту «Преимуществ»: её можно
листать колесом, свайпом и протяжкой мыши. На узком экране после жеста ближайшая карточка
доводится в центр той же кривой, что и переходы между экранами; на десктопе доводки нет.
CSS-снапа нет намеренно, он срабатывает рывком.

`scene-timing.js` считает прозрачность, сдвиг и масштаб для секции «Продукт»: она висит
на sticky, а мокапы телефона сменяют друг друга по прогрессу трека. Там же лежит инвариант
`2 * hold + fade === 1`, который держит сумму прозрачностей соседних сцен ровно на единице,
иначе на пересменке появляется провал в пустой кадр. Все подписчики пересчитываются в общем
rAF-цикле после Lenis, чтобы движение шло кадр в кадр.

## Правила текстов

- Длинных тире в текстах нет, фразы переписываются под обычный дефис или запятую.
- В заголовках и подписях на Nata Sans (H1, тайтлы карточек, подписи цифр) не используется
  буква «ф»: у шрифта нет подходящего начертания этого знака. В Noto Sans она допустима.
- Переносы держит функция `typo()` в `App.jsx`: короткие слова и предлоги не отрываются от
  следующего слова. Вторым аргументом отключается склейка последних двух слов, так сделано
  в карточках преимуществ.

## Заменить перед публикацией

- Secrets EmailJS в environment DEPLOY и локальный `.env` для разработки.
- Телефон `+7 495 975-97-90` и почта `welcome@telier.ru` взяты из макета, стоит подтвердить.
- Карточки в «Преимуществах» показывают пустые серые плашки `.usp-media`, картинок для них нет.
- `hero-hand.png` весит 1.8 МБ, перед выкладкой его стоит пережать.
- Тегов Open Graph нет, для ссылок в мессенджерах их придётся добавить вместе с картинкой.
